# Bing Wallpaper HD

Chrome 扩展：每天自动静默拉取 Bing 每日一图，缓存到扩展私有存储（IndexedDB），新标签页展示壁纸、搜索与最常访问站点；安装或打开新标签页时自动补齐最近 7 天，历史图用 1080p 控制体积，不占用下载目录、不触发下载提示。

## 功能

- **每日更新**：默认每天 6:00，可配置；安装、启动、打开新标签页时自动补齐。
- **画质可选**：UHD（3840×2160）/ 1920×1200 / 1920×1080 / 1366×768 / 1280×720，或自定义 320×240 ~ 7680×4320 的任意宽高（由 Bing 服务端缩放）。
- **日期与时间**：新标签页显示日期和精确到秒的时钟，可配置 12/24 小时制、是否显示秒、日期格式或整体隐藏。
- **收藏**：收藏的图片不会被保留期清理或配额淘汰。
- **固定**：把任意一张历史壁纸固定为新标签页背景，固定期间不跟随每日更新；固定图自动收藏，取消收藏会同时解除固定。
- **保存原图**：`bing-YYYYMMDD-标题.jpg` 直接下载到本地。
- **缓存管理**：查看图片数、占用与收藏数，按收藏清理。
- **可读性自适应**：按图片明暗自动切换文字与阴影配色。
- **站点图标**：优先站点声明的 SVG 或高清图标，其余回退 Chrome favicon。

## 安装

1. `npm run icons` 生成图标（已生成可跳过）
2. Chrome 打开 `chrome://extensions`，开启「开发者模式」
3. 「加载已解压的扩展程序」，选择本目录

## 设置

扩展详情页点击「扩展程序选项」，或右键扩展图标选择「选项」。画质、地区、保留天数、更新时间、日期时间显示修改后立即生效。
